# La documentazione italiana si è spostata

La versione italiana non è più un file separato: ora vive **nella pagina principale della repository**, insieme a quella inglese.

Aprire un file separato faceva uscire dalla pagina del progetto e portava al visualizzatore di file di GitHub. Ora basta un clic sulla barra **🇮🇹 Italiano** e la documentazione si apre restando dove sei.

Il pulsante qui sotto ti porta a quella barra: cliccala per aprire il testo.
